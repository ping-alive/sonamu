## @api 데코레이터

<AccordionGroup>
<Accordion title="@api 데코레이터는 어떻게 사용하나요?">

`@api` 데코레이터를 Model이나 Frame 클래스의 메서드에 붙여 REST API 엔드포인트를 생성합니다.

**기본 사용:**

```typescript
class UserModelClass extends BaseModelClass {
  @api({ httpMethod: "GET" })
  async getProfile(id: number): Promise<UserSubsetMapping["A"]> {
    return this.findById("A", id);
  }

  @api({ httpMethod: "POST" })
  async saveUsers(spa: UserSaveParams[]): Promise<number[]> {
    return this.save(spa);
  }

  @api({ httpMethod: "DELETE" })
  async deleteUsers(ids: number[]): Promise<number> {
    return this.del(ids);
  }
}
```

**자동 생성되는 엔드포인트:**

```
GET    /api/user/getProfile?id=1
POST   /api/user/saveUsers
DELETE /api/user/deleteUsers
```

기본 `api.route.prefix`가 `/api`이면 경로는 `/api/{model}/{method}`입니다. GET은 query string에서, 그 밖의 메서드는 JSON body에서 파라미터를 읽습니다.

</Accordion>

<Accordion title="@api 데코레이터의 옵션들은 무엇인가요?">

**httpMethod (기본값: `"GET"`):**

```typescript
@api({ httpMethod: "GET" | "POST" | "PUT" | "DELETE" | "PATCH" })
```

**guards (인증/권한):**

```typescript
// 인증 및 권한 필요
@api({
  httpMethod: "POST",
  guards: ["user", "admin"]  // user 로그인 필요, admin 권한 필요
})
async adminOnly() { }

// 공개 API (인증 불필요)
@api({
  httpMethod: "GET"
  // guards를 생략하면 인증 없이 접근 가능
})
async publicApi() { }
```

<Info>
  **공개 API 만들기**: `guards` 옵션을 생략하면 인증 없이 누구나 접근할 수 있는 공개 API가 됩니다.
  로그인이나 권한 체크가 필요 없는 경우에 사용하세요.
</Info>

**path (커스텀 경로):**

```typescript
@api({
  httpMethod: "GET",
  path: "/custom/path"  // /user/method 대신 /custom/path 사용
})
async customPath() { }
```

</Accordion>

<Accordion title="GET 요청에서 파라미터를 받으려면?">

**쿼리 파라미터 (단일 값):**

```typescript
@api({ httpMethod: "GET" })
async getUser(id: number, includeProfile?: boolean): Promise<User> {
  // GET /user/getUser?id=1&includeProfile=true
}
```

**쿼리 파라미터 (객체):**

```typescript
@api({ httpMethod: "GET" })
async listUsers(listParams: UserListParams): Promise<ListResult<UserListParams, User>> {
  // GET /user/listUsers?num=20&page=1&orderBy=id-desc
  return this.list("A", listParams);
}
```

</Accordion>

<Accordion title="POST 요청에서 body를 받으려면?">

**단일 객체:**

```typescript
@api({ httpMethod: "POST" })
async createUser(params: UserSaveParams): Promise<User> {
  // POST /user/createUser
  // Body: { name: "John", email: "john@example.com" }
  return this.save(params);
}
```

**다중 파라미터:**

```typescript
@api({ httpMethod: "POST" })
async updateProfile(
  userId: number,
  profile: ProfileSaveParams
): Promise<Profile> {
  // POST /user/updateProfile
  // Body: { userId: 1, profile: { bio: "..." } }
  return ProfileModel.save({ user_id: userId, ...profile });
}
```

</Accordion>

<Accordion title="파일 업로드 API를 만들려면?">

`@upload` 데코레이터는 `@api` 없이 독립적으로 사용합니다.

**단일 파일:**

```typescript
import { upload, Sonamu } from "sonamu";

@upload()
async uploadAvatar(): Promise<{ url: string; filename: string }> {
  // POST /user/uploadAvatar
  // Content-Type: multipart/form-data

  const { bufferedFiles } = Sonamu.getContext();
  const file = bufferedFiles?.[0]; // 첫 번째 파일 사용

  if (!file) {
    throw new Error("파일이 필요합니다");
  }

  const md5 = await file.md5();
  const key = `avatars/${md5}.${file.extname}`;
  const url = await file.saveToDisk("fs", key);

  return { url, filename: file.filename };
}
```

**다중 파일:**

```typescript
import { upload, Sonamu } from "sonamu";

@upload()
async uploadFiles(): Promise<{ files: Array<{ url: string; filename: string }> }> {
  // POST /user/uploadFiles
  // Content-Type: multipart/form-data

  const { bufferedFiles } = Sonamu.getContext();

  if (!bufferedFiles || bufferedFiles.length === 0) {
    throw new Error("파일이 필요합니다");
  }

  const results = [];
  for (const file of bufferedFiles) {
    const md5 = await file.md5();
    const key = `files/${md5}.${file.extname}`;
    const url = await file.saveToDisk("fs", key);
    results.push({ url, filename: file.filename });
  }

  return { files: results };
}
```

</Accordion>

<Accordion title="에러를 반환하려면?">

**BadRequestException (400):**

```typescript
import { BadRequestException } from "sonamu";

@api({ httpMethod: "POST" })
async createUser(params: UserSaveParams): Promise<User> {
  if (!params.email) {
    throw new BadRequestException("이메일은 필수입니다");
  }
  return this.save(params);
}
```

**UnauthorizedException (401):**

```typescript
import { UnauthorizedException } from "sonamu";

@api({ httpMethod: "GET" })
async getMyProfile(): Promise<User> {
  const userId = Sonamu.getContext().user?.id;
  if (!userId) {
    throw new UnauthorizedException("로그인이 필요합니다");
  }
  return this.findById("A", userId);
}
```

**권한 오류 (403):**

```typescript
import { UnauthorizedException } from "sonamu";

@api({ httpMethod: "DELETE" })
async deleteUser(id: number): Promise<void> {
  const currentUser = Sonamu.getContext().user;
  if (currentUser?.role !== "admin") {
    throw new UnauthorizedException("관리자 권한이 필요합니다");
  }
  await this.del(id);
}
```

**NotFoundException (404):**

생성된 `findById`는 레코드가 없으면 이미 `NotFoundException`을 던집니다. 직접 처리하려면 `null`을 반환하는 `findOne`을 쓰세요:

```typescript
import { NotFoundException } from "sonamu";

@api({ httpMethod: "GET" })
async getUserOrFail(id: number): Promise<UserSubsetMapping["A"]> {
  const user = await this.findOne("A", { id });
  if (!user) {
    throw new NotFoundException("사용자를 찾을 수 없습니다");
  }
  return user;
}
```

</Accordion>
</AccordionGroup>

## Context와 세션

<AccordionGroup>
<Accordion title="현재 로그인한 사용자 정보를 가져오려면?">

```typescript
import { Sonamu } from "sonamu";

@api({ httpMethod: "GET" })
async getMyProfile(): Promise<User> {
  const context = Sonamu.getContext();
  const userId = context.user?.id;

  if (!userId) {
    throw new UnauthorizedException("로그인이 필요합니다");
  }

  return this.findById("A", userId);
}
```

</Accordion>

<Accordion title="Context에는 어떤 정보가 있나요?">

```typescript
const context = Sonamu.getContext();

// 인증 정보 (better-auth)
context.user; // 로그인한 사용자 (null이면 미인증)
context.session; // 세션 (null이면 미인증)
context.user?.id; // 사용자 ID

// 요청 정보
context.transport; // "http" | "ws"
context.headers; // 요청 헤더 (IncomingHttpHeaders)
context.headers["user-agent"]; // User-Agent
context.locale; // 현재 요청의 locale

// Fastify 객체 (transport === "http"일 때)
context.request; // FastifyRequest (context.request.ip로 클라이언트 IP)
context.reply; // FastifyReply

// Naite 로그 스토어
context.naiteStore;
```

<Info>
  `userId`/`ip`/`userAgent`는 Context의 최상위 속성이 아닙니다. 각각 `context.user?.id`,
  `context.request.ip`, `context.headers["user-agent"]`로 접근하세요.
</Info>

</Accordion>

<Accordion title="세션을 사용하려면?">

세션은 better-auth가 관리합니다. `server.auth`로 켜며, 별도의 세션 설정은 없습니다.

```typescript
// sonamu.config.ts
export default defineConfig({
  server: {
    auth: {
      emailAndPassword: { enabled: true },
      session: {
        expiresIn: 60 * 60 * 24, // 24시간 (초 단위)
      },
    },
  },
});
```

**로그인 / 로그아웃**: 클라이언트가 better-auth 엔드포인트(`POST /api/auth/sign-in/email`,
`POST /api/auth/sign-out`)를 호출하며, 보통 `better-auth/react`의 `authClient`를 사용합니다. 세션에 값을
저장하는 로그인 API를 직접 만들지 않습니다.

**세션 읽기**는 어느 API에서나 할 수 있습니다:

```typescript
@api({ httpMethod: "GET" })
async getMyInfo() {
  const { user, session } = Sonamu.getContext();

  if (!user || !session) {
    throw new UnauthorizedException("로그인이 필요합니다");
  }

  return this.findById("A", user.id);
}
```

`session`은 읽기 전용 세션 메타데이터(`expiresAt`, `ipAddress`, `userAgent` 등)입니다. 사용자별 데이터는
세션이 아니라 직접 만든 엔티티에 저장하세요.

→ [세션 관리](/ko/api-development/authentication/session-management)

</Accordion>
</AccordionGroup>

## 인증과 권한

<AccordionGroup>
<Accordion title="Guards를 사용하여 권한을 제어하려면?">

**Guard 구현:** guard 키(`user`, `admin`, `query`)는 `server.apiConfig.guardHandler`에서 검사합니다.
요청 Context 안에서 실행되므로 `Sonamu.getContext()`로 현재 `user`를 읽을 수 있습니다. 요청을
거부하려면 예외를 던지세요.

```typescript
// sonamu.config.ts
import { defineConfig, Sonamu, UnauthorizedException } from "sonamu";

export default defineConfig({
  server: {
    auth: {
      emailAndPassword: { enabled: true },
    },
    apiConfig: {
      // ... contextProvider
      guardHandler: (guard) => {
        const { user } = Sonamu.getContext();

        if (guard === "user" && !user) {
          throw new UnauthorizedException("로그인이 필요합니다");
        }
        // User 엔티티에 role 필드를 추가해야 합니다
        if (guard === "admin" && (user as { role?: string } | null)?.role !== "admin") {
          throw new UnauthorizedException("관리자 권한이 필요합니다");
        }
      },
    },
  },
});
```

**Guards 사용:**

```typescript
// user 로그인 필요
@api({ httpMethod: "GET", guards: ["user"] })
async getMyProfile() {
  const { user } = Sonamu.getContext();
  return this.findById("A", user!.id);
}

// admin 권한 필요
@api({ httpMethod: "DELETE", guards: ["admin"] })
async deleteUsers(ids: number[]): Promise<number> {
  return this.del(ids);
}
```

<Info>
  guard를 여러 개 지정하면 `guardHandler`가 각 guard에 대해 순서대로 실행되므로 모두 통과해야 합니다.
  `guards: ["user", "admin"]`은 "user 또는 admin"이 아니라 "로그인했고 admin"이라는 뜻입니다.
</Info>

→ [보호된 라우트](/ko/api-development/authentication/protected-routes)

</Accordion>
</AccordionGroup>

## 응답 형식

<AccordionGroup>
<Accordion title="API 응답을 커스터마이징하려면?">

**기본 응답:**

```typescript
@api({ httpMethod: "GET" })
async getUser(id: number): Promise<UserSubsetMapping["A"]> {
  return this.findById("A", id);
}

// 응답:
// {
//   "id": 1,
//   "name": "John",
//   "email": "john@example.com"
// }
```

**커스텀 응답:**

```typescript
@api({ httpMethod: "GET" })
async getUserWithStats(id: number): Promise<{
  user: UserSubsetMapping["A"];
  stats: { postCount: number };
}> {
  const user = await this.findById("A", id);
  const { postCount } = await this.getPuri("r")
    .table("posts")
    .select({ postCount: Puri.count() })
    .where("posts.user_id", id)
    .first();

  return {
    user,
    stats: { postCount },
  };
}
```

**헤더 설정:**

```typescript
@api({ httpMethod: "GET", contentType: "application/octet-stream" })
async downloadReport(id: number): Promise<Buffer> {
  const { reply } = Sonamu.getContext();
  reply.header("Content-Disposition", `attachment; filename="report-${id}.pdf"`);

  return buildReportPdf(id); // Buffer를 반환하는 직접 만든 함수
}
```

</Accordion>

<Accordion title="페이지네이션 응답을 반환하려면?">

**ListResult 사용:**

```typescript
@api({ httpMethod: "GET" })
async listUsers(
  listParams: UserListParams,
): Promise<ListResult<UserListParams, UserSubsetMapping["A"]>> {
  // ListResult = { rows: T[], total: number }
  return this.findMany("A", listParams);
}

// {
//   "rows": [
//     { "id": 1, "name": "John" },
//     { "id": 2, "name": "Jane" }

//   "total": 100
```

## 프론트엔드 연동

<AccordionGroup>
<Accordion title="자동 생성된 클라이언트 코드를 사용하려면?">

**서비스 파일 자동 생성:**

Model 파일이 변경되면 Sonamu가 각 sync 대상의 `services.generated.ts`를 다시 생성합니다. Model마다 fetch 함수와, `tanstack-query` 클라이언트의 경우 hook을 담은 `{Entity}Service` namespace가 생깁니다.

```typescript
// web/src/services/services.generated.ts (자동 생성)
export namespace UserService {
  export async function getUser<T extends UserSubsetKey>(
    subset: T,
    id: number,
  ): Promise<UserSubsetMapping[T]> {
    return fetch({
      method: "GET",
      url: `/api/user/findById?${qs.stringify({ subset, id })}`,
    });
  }

  export const useUser = <T extends UserSubsetKey>(
    subset: T,
    id: number,
    options?: { enabled?: boolean },
  ) => useRefreshable(useQuery({ ...getUserQueryOptions(subset, id), ...options }));

  // ...
}
```

**React에서 사용:**

```typescript
import { useEffect, useState } from "react";
import { UserService } from "@/services/services.generated";
import type { UserSubsetMapping } from "@/services/sonamu.generated";

function UserProfile({ userId }: { userId: number }) {
  const [user, setUser] = useState<UserSubsetMapping["A"] | null>(null);

  useEffect(() => {
    UserService.getUser("A", userId).then(setUser);
  }, [userId]);

  return <div>{user?.name}</div>;
}
```

**TanStack Query hook 사용:**

```typescript
import { UserService } from "@/services/services.generated";

function UserProfile({ userId }: { userId: number }) {
  const { data: user, error, isLoading } = UserService.useUser("A", userId);

  if (isLoading) return <div>로딩 중...</div>;
  if (error) return <div>에러: {error.message}</div>;

  return <div>{user?.name}</div>;
}
```
