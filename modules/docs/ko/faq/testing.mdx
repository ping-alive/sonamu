## 테스트 기본

<AccordionGroup>
<Accordion title="Sonamu는 어떤 테스트 프레임워크를 사용하나요?">

Sonamu는 **Vitest**를 사용합니다.

**특징:**

- Vite 기반으로 매우 빠른 실행 속도
- Jest 호환 API
- TypeScript 네이티브 지원
- HMR 지원

</Accordion>

<Accordion title="테스트를 실행하려면?">

```bash
# 모든 테스트 실행
pnpm test

# 특정 파일만 실행
pnpm test user.model.test.ts

# Watch 모드 (파일 변경 감지)
pnpm test --watch

# Coverage 리포트
pnpm test --coverage

# UI 모드
pnpm test --ui
```

</Accordion>

<Accordion title="테스트 파일을 생성하려면?">

**Scaffolding으로 생성:**

1. Sonamu UI 접속
2. Scaffolding 탭
3. Entity 선택
4. Template: `model_test` 선택
5. Generate 클릭

**자동 생성되는 파일:**

```typescript
// user.model.test.ts
import { beforeAll, describe, expect, test } from "vitest";
import { UserModel } from "./user.model";

beforeAll(async () => {
  await UserModel.setTestData();
});

describe("UserModel", () => {
  test("findById", async () => {
    const user = await UserModel.findById("A", 1);
    expect(user).toBeDefined();
    expect(user.id).toBe(1);
  });

  test("save", async () => {
    const user = await UserModel.save({
      name: "Test User",
      email: "test@example.com",
    });
    expect(user.id).toBeGreaterThan(0);
    expect(user.name).toBe("Test User");
  });
});
```

</Accordion>
</AccordionGroup>

<AccordionGroup>
<Accordion title="테스트 데이터를 준비하려면?">

**setTestData() 메서드:**

```typescript
// user.model.ts
class UserModelClass extends BaseModelClass {
  async setTestData() {
    const wdb = this.getPuri("w");
    await wdb.table("users").delete();

    await wdb.table("users").insert([
      { id: 1, name: "John", email: "john@example.com" },
      { id: 2, name: "Jane", email: "jane@example.com" },
      { id: 3, name: "Bob", email: "bob@example.com" },
    ]);
  }
}
```

**테스트에서 사용:**

```typescript
import { beforeAll, describe, test } from "vitest";

beforeAll(async () => {
  await UserModel.setTestData();
  await PostModel.setTestData();
  await CommentModel.setTestData();
});

describe("UserModel", () => {
  test("findById", async () => {
    const user = await UserModel.findById("A", 1);
    expect(user.name).toBe("John");
  });
});
```

</Accordion>

## 고급 테스트

<AccordionGroup>
<Accordion title="트랜잭션을 테스트하려면?">

```typescript
import { Puri } from "sonamu";

describe("Transactions", () => {
  test("트랜잭션 성공", async () => {
    const wdb = UserModel.getPuri("w");

    await wdb.transaction(async () => {
      // 트랜잭션 컨텍스트 안에서 호출하는 Model.save() 도 동일 트랜잭션에 자동 합류합니다.
      const [userId] = await UserModel.save([{ name: "Tx User" }]);
      const [profileId] = await ProfileModel.save([{ user_id: userId, bio: "Bio" }]);

      expect(userId).toBeGreaterThan(0);
      expect(profileId).toBeGreaterThan(0);
    });
  });

  test("트랜잭션 롤백", async () => {
    const rdb = UserModel.getPuri("r");
    const before = await rdb.table("users").select({ total: Puri.count() }).first();

    const wdb = UserModel.getPuri("w");
    await expect(
      wdb.transaction(async () => {
        await UserModel.save([{ name: "Rollback User" }]);
        throw new Error("강제 에러");
      }),
    ).rejects.toThrow("강제 에러");

    const after = await rdb.table("users").select({ total: Puri.count() }).first();
    expect(after?.total).toBe(before?.total); // 변화 없음
  });
});
```

</Accordion>

<Accordion title="Mock을 사용하려면?">

```typescript
import { vi } from "vitest";

describe("Mocking", () => {
  test("외부 서비스 Mock", async () => {
    // EmailService.send를 Mock
    const sendMock = vi.spyOn(EmailService, "send").mockResolvedValue({ success: true });

    await UserModel.sendWelcomeEmail(1);

    expect(sendMock).toHaveBeenCalledTimes(1);
    expect(sendMock).toHaveBeenCalledWith(
      expect.objectContaining({
        to: "john@example.com",
        subject: "Welcome!",
      }),
    );

    sendMock.mockRestore();
  });

  test("Date.now Mock", async () => {
    const mockDate = new Date("2025-01-01");
    vi.setSystemTime(mockDate);

    const user = await UserModel.save({ name: "Test" });
    expect(user.created_at).toEqual(mockDate);

    vi.useRealTimers();
  });
});
```

## Best Practices

<AccordionGroup>
<Accordion title="테스트 작성 시 주의사항">

**DO:**

- ✅ 각 테스트는 독립적으로 실행 가능해야 함
- ✅ `beforeAll`이나 `beforeEach`로 테스트 데이터 초기화
- ✅ 의미 있는 테스트 이름 사용
- ✅ 하나의 테스트에서 하나의 기능만 테스트
- ✅ 에러 케이스도 반드시 테스트

**DON'T:**

- ❌ 테스트 간 의존성 만들지 않기
- ❌ 실제 외부 서비스 호출하지 않기 (Mock 사용)
- ❌ 프로덕션 DB 사용하지 않기
- ❌ 하드코딩된 ID나 날짜 사용 지양
- ❌ 테스트 실패를 무시하지 않기

</Accordion>
</AccordionGroup>
