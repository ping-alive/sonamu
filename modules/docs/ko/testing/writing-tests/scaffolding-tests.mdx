## 테스트 파일 생성

### 명령어

```bash
pnpm generate
```

Entity가 정의되어 있으면 자동으로 `{model}.test.ts` 파일이 생성됩니다.

**생성 위치**:

```
api/src/models/
├── user.model.ts
├── user.model.test.ts       # 자동 생성됨
├── post.model.ts
└── post.model.test.ts        # 자동 생성됨
```

### 생성된 파일 구조

```typescript
// api/src/models/user.model.test.ts
import { bootstrap, test } from "sonamu/test";
import { expect, vi } from "vitest";
import { UserModel } from "./user.model";

// 테스트 환경 초기화
bootstrap(vi);

test("사용자 생성", async () => {
  // 테스트 코드 작성
  const [userId] = await UserModel.save([{
    username: "john",
    email: "john@example.com",
    password: "password123",
  }]);
  const user = await UserModel.findById("A", userId);

  expect(user.id).toBeGreaterThan(0);
  expect(user.username).toBe("john");
});

test("사용자 조회", async () => {
  // 테스트 데이터 생성
  const [userId] = await UserModel.save([{
    username: "jane",
    email: "jane@example.com",
    password: "password123",
  }]);
  const user = await UserModel.findById("A", userId);

  // 조회 테스트
  const found = await UserModel.findById("A", user.id);

  expect(found.id).toBe(user.id);
  expect(found.username).toBe("jane");
});
```

## 테스트 실행

### 단일 파일 실행

```bash
# 특정 모델 테스트만 실행
pnpm vitest user.model.test.ts
```

### 전체 테스트 실행

```bash
# 모든 테스트 실행
pnpm test

# 또는
pnpm vitest
```

### Watch 모드

```bash
# 파일 변경 시 자동 재실행
pnpm vitest --watch
```

## 테스트 작성 가이드

### CRUD 테스트 패턴

```typescript
import { NotFoundException } from "sonamu";
import { bootstrap, test } from "sonamu/test";
import { expect, vi } from "vitest";
import { PostModel } from "./post.model";

bootstrap(vi);

// Create
test("게시글 생성", async () => {
  const [postId] = await PostModel.save([{
    title: "Test Post",
    content: "Test Content",
    author_id: 1,
  }]);
  const post = await PostModel.findById("A", postId);

  expect(post.id).toBeGreaterThan(0);
  expect(post.title).toBe("Test Post");
});

// Read
test("게시글 조회", async () => {
  // 테스트 데이터 생성
  const [postId] = await PostModel.save([{
    title: "Test Post",
    content: "Test Content",
    author_id: 1,
  }]);
  const post = await PostModel.findById("A", postId);

  // 조회
  const found = await PostModel.findById("A", post.id);

  expect(found.id).toBe(post.id);
  expect(found.title).toBe("Test Post");
});

// Update
test("게시글 수정", async () => {
  // 테스트 데이터 생성
  const [postId] = await PostModel.save([{
    title: "Original Title",
    content: "Original Content",
    author_id: 1,
  }]);
  const post = await PostModel.findById("A", postId);

  // 수정
  await PostModel.getPuri("w").table("posts").where("id", post.id).update({
    title: "Updated Title",
  });

  // 확인
  const updated = await PostModel.findById("A", post.id);
  expect(updated.title).toBe("Updated Title");
  expect(updated.content).toBe("Original Content"); // 변경 안 됨
});

// Delete
test("게시글 삭제", async () => {
  // 테스트 데이터 생성
  const [postId] = await PostModel.save([{
    title: "Test Post",
    content: "Test Content",
    author_id: 1,
  }]);
  const post = await PostModel.findById("A", postId);

  // 삭제
  await PostModel.del([post.id]);

  // 확인
  // 생성된 findById는 행이 없으면 NotFoundException을 던집니다
  await expect(PostModel.findById("A", post.id)).rejects.toThrow(NotFoundException);
});
```

### 관계 테스트

```typescript
test("사용자와 게시글 관계", async () => {
  // 사용자 생성
  const [userId] = await UserModel.save([{
    username: "author",
    email: "author@example.com",
    password: "password",
  }]);
  const user = await UserModel.findById("A", userId);

  // 게시글 생성
  const [postId] = await PostModel.save([{
    title: "User's Post",
    content: "Content",
    author_id: user.id,
  }]);
  const post = await PostModel.findById("A", postId);

  // 관계 확인
  expect(post.author_id).toBe(user.id);

  // Subset "C"로 조회하면 author 정보 포함
  const fullPost = await PostModel.findById("A", post.id);
  expect(fullPost.author?.username).toBe("author");
});
```

### 에러 테스트

```typescript
test("중복 이메일 검증", async () => {
  // 첫 번째 사용자 생성
  await UserModel.save([{
    username: "user1",
    email: "duplicate@example.com",
    password: "password",
  }]);

  // 같은 이메일로 다시 생성 시도
  await expect(
    UserModel.save([{
      username: "user2",
      email: "duplicate@example.com",
      password: "password",
    }]),
  ).rejects.toThrow("이미 존재하는 이메일입니다");
});

test("존재하지 않는 게시글 조회", async () => {
  await expect(PostModel.findById("A", 999999)).rejects.toThrow(NotFoundException);
});
```

## 테스트 구조화

### 여러 테스트 그룹화

```typescript
import { bootstrap, test } from "sonamu/test";
import { expect, vi } from "vitest";
import { describe } from "vitest";
import { UserModel } from "./user.model";

bootstrap(vi);

describe("사용자 생성", () => {
  test("정상적인 생성", async () => {
    const [userId] = await UserModel.save([{
      username: "john",
      email: "john@example.com",
      password: "password",
    }]);
    const user = await UserModel.findById("A", userId);
    expect(user.id).toBeGreaterThan(0);
  });

  test("중복 이메일 검증", async () => {
    await UserModel.save([{
      username: "user1",
      email: "duplicate@example.com",
      password: "password",
    }]);

    await expect(
      UserModel.save([{
        username: "user2",
        email: "duplicate@example.com",
        password: "password",
      }]),
    ).rejects.toThrow();
  });
});

describe("사용자 조회", () => {
  test("ID로 조회", async () => {
    const [userId] = await UserModel.save([{
      username: "test",
      email: "test@example.com",
      password: "password",
    }]);
    const user = await UserModel.findById("A", userId);

    const found = await UserModel.findById("A", user.id);
    expect(found.id).toBe(user.id);
  });

  test("존재하지 않는 사용자 조회", async () => {
    await expect(UserModel.findById("A", 999999)).rejects.toThrow();
  });
});
```

## 베스트 프랙티스

### 1. 테스트 격리

각 테스트는 독립적으로 실행되어야 합니다.

```typescript
// ✅ 올바른 방법: 각 테스트가 독립적
test("테스트 1", async () => {
  const [userId] = await UserModel.save([{
    /* ... */
  }]);
  const user = await UserModel.findById("A", userId);
  // 테스트 종료 후 자동 롤백
});

test("테스트 2", async () => {
  // 깨끗한 DB 상태에서 시작
  const [userId] = await UserModel.save([{
    /* ... */
  }]);
  const user = await UserModel.findById("A", userId);
});

// ❌ 잘못된 방법: 테스트 간 의존성
let sharedUserId: number;

test("테스트 1", async () => {
  const [userId] = await UserModel.save([{
    /* ... */
  }]);
  const user = await UserModel.findById("A", userId);
  sharedUserId = user.id; // ❌ 다른 테스트와 공유
});

test("테스트 2", async () => {
  const user = await UserModel.findById("A", sharedUserId); // ❌ 실패함!
});
```

### 2. 명확한 테스트 이름

```typescript
// ✅ 올바른 방법
test("중복 이메일로 사용자 생성 시 에러 발생", async () => {
  // ...
});

// ❌ 잘못된 방법
test("테스트 1", async () => {
  // ...
});
```

### 3. Arrange-Act-Assert 패턴

```typescript
test("게시글 수정", async () => {
  // Arrange (준비)
  const [postId] = await PostModel.save([{
    title: "Original",
    content: "Content",
    author_id: 1,
  }]);
  const post = await PostModel.findById("A", postId);

  // Act (실행)
  await PostModel.getPuri("w").table("posts").where("id", post.id).update({
    title: "Updated",
  });

  // Assert (검증)
  const updated = await PostModel.findById("A", post.id);
  expect(updated.title).toBe("Updated");
});
```

## 주의사항

<Warning>
  **테스트 작성 시 주의사항**: 1. **자동 생성 파일 수정 금지**: 재생성 시 덮어씌워집니다 2.
  **독립적인 테스트**: 테스트 간 의존성 없어야 함 3. **Transaction 기반**: 각 테스트 종료 후 자동
  롤백 4. **비동기 필수**: 모든 테스트는 async 함수 5. **명확한 이름**: 테스트가 무엇을 검증하는지
  명확하게
</Warning>
