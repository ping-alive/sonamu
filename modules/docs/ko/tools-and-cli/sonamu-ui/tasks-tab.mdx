Tasks 탭은 **워크플로우 실행 상태를 모니터링하고 관리하는 기능**을 제공합니다. 등록된 워크플로우 정의를 확인하고, 실행 중인 워크플로우를 추적하며, 필요시 실행을 취소할 수 있습니다.

<Info>
  Tasks 탭은 [@sonamu-kit/tasks](https://github.com/ping-alive/sonamu/tree/master/modules/tasks)
  모듈과 연동됩니다. 워크플로우가 정의되어 있지 않으면 빈 화면이 표시됩니다.
</Info>

## 화면 구성

Tasks 탭은 세 가지 주요 섹션으로 구성됩니다:

### 1. 실행 중인 워크플로우 (Active Workflows)

현재 실행 중인 워크플로우가 있을 때만 표시되는 섹션입니다.

| 정보                | 설명                                     |
| ------------------- | ---------------------------------------- |
| **워크플로우 이름** | 클릭하면 상세 화면으로 이동              |
| **상태**            | `PENDING`, `RUNNING`, `SLEEPING` 중 하나 |
| **Step 진행도**     | 현재까지 실행된 Step들의 타임라인        |
| **경과 시간**       | 실시간으로 업데이트되는 경과 시간        |
| **취소 버튼**       | 실행 중인 워크플로우를 취소              |

<Warning>
  워크플로우 취소는 즉시 적용되지 않을 수 있습니다. 현재 실행 중인 Step이 완료된 후 취소됩니다.
</Warning>

### 2. 등록된 워크플로우 (Workflow Definitions)

프로젝트에 정의된 모든 워크플로우 목록을 표시합니다.

| 컬럼              | 설명                                      |
| ----------------- | ----------------------------------------- |
| **워크플로우**    | 워크플로우 이름                           |
| **버전**          | 워크플로우 버전 (없으면 `(unversioned)`)  |
| **스케줄**        | cron 표현식으로 정의된 스케줄 (있는 경우) |
| **리트라이 정책** | 최대 시도 횟수, 초기 간격, 백오프 배수 등 |

### 3. 워크플로우 실행 기록 (Workflow Runs)

모든 워크플로우 실행 기록을 시간순으로 표시합니다.

| 컬럼           | 설명                                                                 |
| -------------- | -------------------------------------------------------------------- |
| **워크플로우** | 클릭하면 상세 화면으로 이동                                          |
| **버전**       | 실행된 워크플로우의 버전                                             |
| **상태**       | `PENDING`, `RUNNING`, `SLEEPING`, `SUCCEEDED`, `FAILED`, `CANCELLED` |
| **시도**       | 재시도 횟수                                                          |
| **생성**       | 워크플로우가 생성된 시간                                             |
| **시작**       | 실제 실행이 시작된 시간                                              |
| **종료**       | 실행이 완료된 시간                                                   |
| **소요 시간**  | 시작부터 종료까지 걸린 시간                                          |

## 워크플로우 상세 화면

실행 기록에서 워크플로우 이름을 클릭하면 상세 화면으로 이동합니다.

### 기본 정보

상세 화면 상단에는 다음 정보가 표시됩니다:

- **워크플로우 이름** 및 **ID**
- **현재 상태** (상태에 따라 색상으로 구분)
- **버전**, **시도 횟수**, **생성/시작/종료 시간**, **소요 시간**
- **Worker ID**, **Namespace**

### Input/Output

워크플로우에 전달된 입력값과 결과값을 JSON 형식으로 확인할 수 있습니다. 클릭하면 펼쳐집니다.

### 에러 정보

워크플로우가 실패한 경우, 에러 이름, 메시지, 스택 트레이스가 표시됩니다.

### Step Attempts

워크플로우 내에서 실행된 모든 Step들의 목록입니다. 각 행을 클릭하면 상세 정보가 펼쳐집니다:

| 정보               | 설명                                  |
| ------------------ | ------------------------------------- |
| **Step**           | Step 이름                             |
| **종류**           | `activity` 또는 `sleep`               |
| **상태**           | `RUNNING`, `SUCCEEDED`, `FAILED` 등   |
| **시작/종료 시간** | Step의 실행 시간                      |
| **Output**         | Step이 반환한 결과값 (펼침 시)        |
| **에러**           | Step 실행 중 발생한 에러 (펼침 시)    |
| **Context**        | Step 실행 컨텍스트 (펼침 시)          |
| **Child Workflow** | 하위 워크플로우가 있는 경우 링크 표시 |

## 자동 새로고침

워크플로우 실행 기록은 **5초마다 자동으로 새로고침**됩니다. 수동으로 새로고침하려면 우측 상단의 새로고침 버튼을 클릭하세요.

## 페이지네이션

실행 기록이 많은 경우 커서 기반 페이지네이션이 적용됩니다. 하단의 이전/다음 버튼으로 페이지를 이동할 수 있습니다.

## 상태별 색상

| 상태        | 색상   | 설명                 |
| ----------- | ------ | -------------------- |
| `PENDING`   | 노란색 | 실행 대기 중         |
| `RUNNING`   | 파란색 | 실행 중              |
| `SLEEPING`  | 보라색 | sleep Step 실행 중   |
| `SUCCEEDED` | 초록색 | 성공적으로 완료      |
| `FAILED`    | 빨간색 | 실패                 |
| `CANCELLED` | 회색   | 사용자에 의해 취소됨 |
