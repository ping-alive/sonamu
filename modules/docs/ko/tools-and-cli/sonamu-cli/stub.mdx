`pnpm sonamu stub` 명령어는 반복 작업을 줄이기 위한 **코드 템플릿**을 자동 생성합니다. Practice 스크립트나 새 Entity를 빠르게 만들 수 있어 개발 속도를 높입니다.

## 명령어

### practice - Practice 스크립트 생성

임시 실험이나 데이터 처리를 위한 스크립트를 생성합니다.

```bash
pnpm sonamu stub practice <name>
```

**예시**:

```bash
pnpm sonamu stub practice test-api

# 생성됨:
# src/practices/p1-test-api.ts
# 생성한 파일 이름과 경로만 출력하며,
# 에디터를 열거나 클립보드에 복사하는 부수 효과는 없습니다.
```

**생성된 파일**:

```typescript title="src/practices/p1-test-api.ts"
import { Sonamu } from "sonamu";

console.clear();
console.log("p1-test-api.ts");

Sonamu.runScript(async () => {
  // TODO
});
```

**실행**:

```bash
# 빌드한 뒤 컴파일된 practice 스크립트를 실행합니다
pnpm node -r dotenv/config --enable-source-maps dist/practices/p1-test-api.js
```

<Note>
  practice 이름에는 영문자, 숫자, `.`, `-`, `_`만 사용할 수 있고 첫 글자는 영문자나 숫자여야
  합니다. 그 외의 이름은 거절하며, 이미 있는 practice 파일은 덮어쓰지 않습니다.
</Note>

### entity - Entity 생성

새로운 Entity를 생성합니다. 기본적으로 Entity 생성 후 **템플릿 cone**이 자동으로 함께 생성됩니다.

```bash
pnpm sonamu stub entity <entityId> [옵션]
```

**옵션**:

| 옵션         | 설명                                                        | 예시                                  |
| ------------ | ----------------------------------------------------------- | ------------------------------------- |
| (없음)       | Entity 생성 후 템플릿 cone 자동 생성 (기본 동작)            | `pnpm sonamu stub entity Product`            |
| `--ai`       | Entity 생성 후 LLM으로 cone 생성 (`ANTHROPIC_API_KEY` 필요) | `pnpm sonamu stub entity Product --ai`       |
| `--no-cones` | Entity만 생성하고 cone 생성을 스킵                          | `pnpm sonamu stub entity Product --no-cones` |

**예시**:

```bash
# 기본: 템플릿 cone과 함께 Entity 생성
pnpm sonamu stub entity Product

# AI를 활용한 cone 생성
pnpm sonamu stub entity Product --ai

# cone 없이 Entity만 생성
pnpm sonamu stub entity Product --no-cones
```

<Note>
  템플릿 cone은 `ANTHROPIC_API_KEY` 없이도 생성할 수 있습니다. 나중에 `cone gen` 명령어로 AI를
  활용해 업그레이드할 수 있습니다.
</Note>

**생성된 파일**:

```json title="src/application/product/product.entity.json"
{
  "id": "Product",
  "title": "Product",
  "table": "products",
  "props": [
    { "name": "id", "type": "integer", "desc": "ID" },
    {
      "name": "created_at",
      "type": "date",
      "desc": "등록일시",
      "dbDefault": "CURRENT_TIMESTAMP"
    }
  ],
  "indexes": [],
  "subsets": { "A": ["id", "created_at"] },
  "enums": {
    "ProductOrderBy": { "id-desc": "ID최신순" },
    "ProductSearchField": { "id": "ID" }
  }
}
```

## Practice 스크립트

### 사용 시나리오

Practice 스크립트는 다음과 같은 작업에 활용됩니다:

| 용도                | 설명                 | 예시                          |
| ------------------- | -------------------- | ----------------------------- |
| API 테스트          | 외부 API 호출 테스트 | `p1-test-payment-api.ts`      |
| 데이터 마이그레이션 | 일회성 데이터 변환   | `p2-migrate-user-data.ts`     |
| 디버깅              | 특정 로직 검증       | `p3-debug-cache-issue.ts`     |
| 데이터 생성         | 테스트 데이터 생성   | `p4-create-sample-posts.ts`   |
| 분석                | 데이터 통계 확인     | `p5-analyze-user-activity.ts` |

### 순서 관리

Practice 파일은 **자동으로 번호가 부여**됩니다:

import { FileTree, FileItem } from "../../../snippets/FileTree.jsx";

<FileTree>
  <FileItem name="src/practices/">
    <FileItem name="p1-first-practice.ts" />
    <FileItem name="p2-second-practice.ts" />
    <FileItem name="p3-third-practice.ts" description="다음은 p4" />
  </FileItem>
</FileTree>

새 practice를 생성하면 가장 큰 번호 + 1이 자동으로 할당됩니다.

### 실전 예제

#### 1. API 테스트

```typescript title="src/practices/p1-test-payment-api.ts"
import { Sonamu } from "sonamu";

console.clear();
console.log("p1-test-payment-api.ts");

Sonamu.runScript(async () => {
  const paymentService = new PaymentService();

  // 테스트 결제 시도
  const result = await paymentService.charge({
    amount: 10000,
    orderId: "TEST-001",
  });

  console.log("결제 결과:", result);
});
```

#### 2. 데이터 마이그레이션

```typescript title="src/practices/p2-migrate-user-data.ts"
import { Sonamu } from "sonamu";
import { UserModel } from "../models/User.model";

console.clear();
console.log("p2-migrate-user-data.ts");

Sonamu.runScript(async () => {
  // 모든 사용자 조회
  const { rows: users } = await UserModel.findMany("A", { num: 0 }); // num: 0이면 개수 제한 없음

  for (const user of users) {
    // legacy 필드를 새 필드로 마이그레이션
    await UserModel.getPuri("w").table("users").where("id", user.id).update({
      new_field: transformData(user.legacy_field),
    });

    console.log(`✓ Migrated user ${user.id}`);
  }

  console.log(`\n✓ Total: ${users.length} users migrated`);
});
```

#### 3. 배치 작업

```typescript title="src/practices/p3-send-welcome-emails.ts"
import { Sonamu } from "sonamu";
import { UserModel } from "../models/User.model";

console.clear();
console.log("p3-send-welcome-emails.ts");

Sonamu.runScript(async () => {
  // 신규 가입 사용자
  const { rows: newUsers } = await UserModel.findMany("A", {
    sonamuFilter: { welcome_email_sent: false },
  });

  console.log(`Sending welcome emails to ${newUsers.length} users...`);

  for (const user of newUsers) {
    try {
      await sendWelcomeEmail(user.email);
      await UserModel.getPuri("w").table("users").where("id", user.id).update({
        welcome_email_sent: true,
      });
      console.log(`✓ Sent to ${user.email}`);
    } catch (error) {
      console.error(`✗ Failed to send to ${user.email}:`, error);
    }
  }
});
```

## Entity 생성

### 기본 구조

`stub entity`로 생성된 Entity는 기본 필드들을 포함합니다:

```json
{
  "id": "Product",
  "title": "Product",
  "table": "products",
  "props": [
    { "name": "id", "type": "integer", "desc": "ID" },
    {
      "name": "created_at",
      "type": "date",
      "desc": "등록일시",
      "dbDefault": "CURRENT_TIMESTAMP"
    }
  ],
  "indexes": [],
  "subsets": { "A": ["id", "created_at"] },
  "enums": {
    "ProductOrderBy": { "id-desc": "ID최신순" },
    "ProductSearchField": { "id": "ID" }
  }
}
```

### 커스터마이징

생성 후 필요한 필드를 추가합니다:

```json
{
  "id": "Product",
  "title": "Product",
  "table": "products",
  "props": [
    { "name": "id", "type": "integer", "desc": "ID" },
    {
      "name": "created_at",
      "type": "date",
      "desc": "등록일시",
      "dbDefault": "CURRENT_TIMESTAMP"
    },
    { "name": "title", "type": "string", "length": 255, "desc": "상품명" },
    { "name": "description", "type": "string", "nullable": true, "desc": "설명" },
    { "name": "price", "type": "numeric", "precision": 10, "scale": 2, "desc": "가격" },
    { "name": "stock", "type": "integer", "desc": "재고", "dbDefault": 0 },
    {
      "type": "relation",
      "name": "category",
      "relationType": "BelongsToOne",
      "with": "Category",
      "onUpdate": "CASCADE",
      "onDelete": "CASCADE",
      "desc": "카테고리"
    }
  ],
  "indexes": [
    { "type": "index", "name": "products_title_index", "columns": [{ "name": "title" }] }
  ],
  "subsets": { "A": ["id", "created_at", "title", "price", "category.id"] },
  "enums": {
    "ProductOrderBy": { "id-desc": "ID최신순" },
    "ProductSearchField": { "id": "ID", "title": "상품명" }
  }
}
```

<Note>
  `category_id` 같은 FK 컬럼은 `relation` prop으로 정의하면 마이그레이션 생성 시 자동으로
  만들어집니다. Entity의 prop 타입과 필드 규칙은
  [Entity 정의하기](/ko/core-concepts/entity/defining-entities)를 참고하세요.
</Note>

## 개발 워크플로우

### 1. 아이디어 검증

```bash
# 빠르게 practice 생성
pnpm sonamu stub practice test-idea

# 코드 작성 및 실행
pnpm node -r dotenv/config --enable-source-maps dist/practices/p1-test-idea.js

# 동작 확인 후 삭제 또는 보관
```

### 2. Entity 추가

```bash
# Entity 생성
pnpm sonamu stub entity Order

# Entity 정의 작성
# src/application/order/order.entity.json

# 마이그레이션 생성 및 적용
pnpm sonamu migrate generate
pnpm sonamu migrate run --execute

# Model 스캐폴딩
pnpm sonamu scaffold model Order
```

### 3. 데이터 작업

```bash
# Practice 스크립트 생성
pnpm sonamu stub practice import-orders

# 데이터 처리 로직 작성
# src/practices/p1-import-orders.ts

# 실행
pnpm node -r dotenv/config --enable-source-maps dist/practices/p1-import-orders.js
```

## 실전 팁

### 1. Practice 스크립트 재사용

```typescript
// ✅ 재사용 가능하도록 함수화
async function processUsers(filter: UserListParams["sonamuFilter"]) {
  const { rows: users } = await UserModel.findMany("A", { sonamuFilter: filter });
  // 처리 로직...
}

Sonamu.runScript(async () => {
  // 다양한 필터로 재사용
  await processUsers({ role: "admin" });
  await processUsers({ role: "user" });
});
```

### 2. 에러 처리

```typescript
Sonamu.runScript(async () => {
  try {
    await riskyOperation();
  } catch (error) {
    console.error("Error occurred:", error);
    process.exit(1); // 실패 시 종료
  }
});
```

### 3. 진행 상황 표시

```typescript
Sonamu.runScript(async () => {
  const { rows: users } = await UserModel.findMany("A", { num: 0 }); // num: 0이면 개수 제한 없음

  for (let i = 0; i < users.length; i++) {
    await processUser(users[i]);

    // 진행률 표시
    const progress = Math.round(((i + 1) / users.length) * 100);
    console.log(`Progress: ${progress}% (${i + 1}/${users.length})`);
  }
});
```
