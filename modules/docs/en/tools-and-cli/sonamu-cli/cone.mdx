The `pnpm sonamu cone gen` command uses AI (LLM) to generate or upgrade **cone metadata** for Entities. You can improve template cones created by `stub entity` with AI, or regenerate existing cones.

## Basic Usage

```bash
pnpm sonamu cone gen <entityId> [options]
```

<Note>
  Requires `ANTHROPIC_API_KEY`. Set it in `sonamu.secret.ts` or as an environment variable.
</Note>

## Options

| Option                  | Description                                                                            | Example                              |
| ----------------------- | -------------------------------------------------------------------------------------- | ------------------------------------ |
| (none)                  | Generate only empty fixtureHints (preserves existing values)                           | `pnpm sonamu cone gen Product`              |
| `--regenerate`          | Overwrite existing cones and regenerate all                                            | `pnpm sonamu cone gen Product --regenerate` |
| `--locale <ko\|en\|ja>` | Specify generation language (default: `sonamu.config.ts` `i18n.defaultLocale` or `ko`) | `pnpm sonamu cone gen Product --locale en`  |
| `all` as the Entity     | Generate cones for all Entities at once                                                | `pnpm sonamu cone gen all`                  |

## Examples

### Generate cones for a single Entity

```bash
pnpm sonamu cone gen Product
```

### Regenerate existing cones

```bash
pnpm sonamu cone gen Product --regenerate
```

### Generate cones in English

```bash
pnpm sonamu cone gen Product --locale en
```

### Batch generate for all Entities

```bash
pnpm sonamu cone gen all
```

## How It Works

### Default mode (onlyEmpty)

When run without options, only fields with empty `fixtureHint` are generated. Existing values are preserved.

### Regenerate mode (`--regenerate`)

With `--regenerate`, all existing cone metadata is overwritten and regenerated from scratch. Be careful if you have manually adjusted values.

## Workflow

A typical cone workflow:

```bash
# 1. Create Entity (includes template cones by default)
pnpm sonamu stub entity Product

# 2. Upgrade cones with AI
pnpm sonamu cone gen Product

# 3. Regenerate in a specific language if needed
pnpm sonamu cone gen Product --regenerate --locale en
```
